# Pradip Engineering Portfolio V15

Experimental single-page portfolio built separately from the live V14 site.

## Local preview
Open `index.html` in a browser.

## GitHub Pages
1. Create a new public repository, recommended name: `engineering-portfolio-v15`
2. Upload every file/folder in this package to the repository root.
3. Commit the files.
4. Go to Settings → Pages.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide a temporary `github.io` URL.

## Important
This test build intentionally has **no CNAME file** and uses `noindex` so it will not take over `pradipsapkota.dev` or compete with the live portfolio in Google while testing.

When V15 is approved for production, update the SEO metadata, remove `noindex`, add the custom domain, and point `pradipsapkota.dev` to this repository.
